# Furniture Expert (коротко українською)

`furniture-expert` — навичка (Agent Skill) для інтернет-магазину меблів в Україні, який перепродає українські фабрики (зі складу або дропшипом) і частину позицій ввозить із Польщі та Китаю. Вона працює як технолог-меблевик і комерційний директор в одній особі: плити, масив і шпон, фурнітура, м'які меблі й матраци, дилерські умови та рекомендовані ціни (RRP), повна собівартість і ціна, контроль якості та рекламації, картки товарів і SEO українською, повернення, гарантія, правила ввезення.

Повний опис англійською — у [README.md](README.md).

## Встановлення в Claude Code

```bash
claude plugin marketplace add dmitriy990/furniture-expert-skills
```

```bash
claude plugin install furniture-expert@ivatech-furniture
```

Далі просто формулюйте завдання: «склади картку дивана», «порахуй ціну дивана з фабрики», «скільки коштуватимуть стільці з Китаю», «перевір цей прайс». Потрібен `python3` у PATH. Інші способи (ручне копіювання, Claude.ai) описані в [README.md](README.md).

## Що вона робить сама

Після виклику навички в Claude Code діють три локальні перевірки (хуки):
- ДСП і МДФ не називаються масивом чи натуральним деревом, а екошкіра — натуральною шкірою;
- габарити в міліметрах не підписуються як сантиметри, а щільність, товщина, Мартіндейл і пружини звіряються з типовими діапазонами;
- дилерські ціни й назви постачальників не потрапляють у публічний текст;
- прайс перевіряється на мінусові ціни, ціни нижче собівартості та зайві нулі, а для виробників зі списку `rrp_enforced_brands` — на ціни нижче RRP;
- юридичні твердження й розрахунки не лишаються без дати та припущень.

Налаштування й виняткові випадки — у [references/hooks.md](references/hooks.md) (російською). Вимкнути: `claude plugin disable furniture-expert`.

Реєстрація хуків відповідає документації Claude Code, але автор не спостерігав її у живій сесії; для цього в `references/hooks.md` є перевірка на одну хвилину.

## Застереження

Це робоча довідка, а **не юридична, митна чи податкова консультація**. Правила захисту прав споживачів, повернення, гарантії, мита, ПДВ і походження змінюються; правові примітки датовані й посилаються на джерела, а чинний закон залежить від воєнного стану. Усе важливе перевіряйте у юриста, митного брокера чи бухгалтера та за первинними джерелами (zakon.rada.gov.ua, customs.gov.ua, tax.gov.ua, dpss.gov.ua). Ці примітки юрист не перевіряв.
