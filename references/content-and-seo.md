# Контент для магазина: карточки, размеры, доставка, SEO, ответы покупателям

Читать при: написании карточек, заголовков, категорийных текстов, фидов, ответов покупателям. **Весь публичный текст — на украинском** (рабочий диалог с владельцем может идти на русском). Хук `lint_content` после каждой записи файла проверяет габариты, параметры, заявления о материалах, недоказанные утверждения и утечки закупочных данных.

## 1. Шаблон карточки товара (украинский)

```markdown
# [Тип виробу] [модель] [оббивка або матеріал] [колір], [Ш×Г×В] см

[1–2 речення: для кого й для якої кімнати, головна перевага. Без «найкращий».]

## Характеристики
| | |
|---|---|
| Габарити (Ш×Г×В) | 230×95×90 см |
| Спальне місце | 200×150 см, висота 45 см |
| Висота / глибина сидіння | 45 / 60 см |
| Каркас | брус сосни, фанера 15 мм |
| Основа сидіння | пружинна змійка |
| Наповнювач | ППУ 35 кг/м³ + холофайбер |
| Оббивка | велюр, 50 000 циклів за Мартіндейлом, склад за паспортом тканини |
| Механізм | єврокнижка, ящик для білизни |
| Колір / декор | … (колір на екрані може відрізнятися) |
| Країна виробництва | … (за документами) |
| Виробник / імпортер | … |
| Гарантія | … міс., від дня доставки (або складання нашим майстром) |
| Складання | потрібне / не потрібне, інструкція українською |
| Упаковка | … місць, … кг, найбільше місце … см |

## Чому це гарний вибір
- (3–5 пунктів, кожен — конкретна характеристика: «єврокнижка розкладається вперед на 50 см — підходить для щоденного сну біля стіни»)

## Догляд
(за інструкцією виробника тканини або покриття)

## Доставка, підйом і складання
Доставка, підйом на поверх і складання оплачуються окремо. Доставка по Києву безкоштовна для замовлень від 19 000 грн за товари; підйом і складання оплачуються й у цьому разі. (Умови станом на [дата].)

## Повернення
[посилання на політику повернення; дата редакції]
```

Для корпусной мебели строки «Каркас / Наповнювач / Оббивка / Механізм» замените на «Корпус», «Фасади», «Стільниця», «Кромка», «Фурнітура». Для матраса — «Розмір», «Висота», «Пружинний блок (пружин на м²)», «Шари зверху вниз», «Жорсткість сторін», «Навантаження на спальне місце», «Чохол».

**Правила описания.**
- Габариты всегда в см и в порядке Ш×Г×В; размер в упаковке — отдельно.
- Материал — по элементам, без «натуральне дерево» для плиты и без «натуральна шкіра» для экокожи (`materials-and-construction.md`, `upholstery-and-mattresses.md`).
- Не утверждать без документов: «ортопедичний», «анатомічний», «гіпоалергенний», «екологічно чистий», «без формальдегіду», классы E0/E1, FSC, «Made in Poland», «європейська якість».
- Товар под заказ — так и писать: «виготовлення під замовлення, … робочих днів», с оговоркой о возврате (`ukraine-legal.md`).
- Рендер подписывать «візуалізація»; цвет ткани — по образцу, предлагать заказ образца.
- Никаких закупочных цен, дилерских скидок, названий фабрик-поставщиков, если это не бренд товара, и ссылок на площадки поставщиков.

## 2. Размеры (ориентиры рынка Украины, см; сверяйте с моделью)

| Что | Размеры |
|---|---|
| Матрас и спальное место кровати | 80×190, 90×200 (односпальне), 120×200 (півторне), 140×200, 160×200 (двоспальне), 180×200, 200×200 |
| Китайские спецификации | Queen ≈ 152×203, King ≈ 193×203 — не называть их «євро»; писать фактические см |
| Спальное место дивана | 140–160 × 190–200 для ежедневного сна; меньше — гостевое |
| Сиденье дивана | высота 42–48, глубина 55–65 |
| Обеденный стол | высота 74–76; 60 см края на человека |
| Стул | высота сиденья 44–48 |
| Письменный стол | высота 72–76 (для детей — регулируемый) |
| Шкаф | глубина 58–60 для плечиков поперёк, 35–45 — для полок |
| Кухня | столешница на высоте 85–92, глубина 60 |

Прикроватная проверка для покупателя: «виміряйте ширину дверей, ліфта й прольотів сходів — найбільше місце в упаковці … см».

## 3. Заголовки, мета-теги, ключевые слова

- **H1** (≤ 70 знаков): тип + модель + ключевой атрибут + размер. Пример: «Кутовий диван Мілан, єврокнижка, велюр сірий, 280×180 см».
- **Title** (≤ 60 знаков) и **meta description** (140–160 знаков): выгода + размер + доставка по Києву від 19 000 грн, если применимо.
- **Ключевые запросы** собирайте кластерами: «диван кутовий з ящиком», «ліжко 160×200 з підйомним механізмом», «матрац 160×200 незалежний блок», «шафа-купе 2 метри». Не дублируйте один кластер на нескольких страницах.
- **Фильтры как посадочные:** розмір, механізм, матеріал, колір, жорсткість, ширина шафи.
- **Категорийный текст:** 300–600 слов, как выбрать (механизм, наполнитель, ткань по Мартиндейлу, размеры), без воды и без перечисления конкурентов.
- **schema.org Product:** name, sku, brand, image, offers (price, priceCurrency UAH, availability), additionalProperty для габаритов и материалов. Не выдумывайте рейтинги и отзывы.
- **Alt фото:** «Кутовий диван Мілан у сірому велюрі, розкладений, вигляд спереду».

## 4. Фото

Реальные фото предпочтительнее рендера; обязательно — фото с размерами (схема), крупно ткань и фурнитура, разложенный механизм, интерьер. Чужие фото и фото поставщика — только с правом использования.

## 5. Ответы покупателям (украинский, шаблоны)

**Пошкодження під час доставки:**
> Перепрошуємо за пошкодження. Надішліть, будь ласка, фото пошкодженого місця й упаковки та номер замовлення. Ми замінимо деталь або виріб за наш рахунок; повторну доставку теж оплачуємо ми. Про строк повідомимо після відповіді виробника, зазвичай …

**Складання, бракує деталі:**
> Дякуємо, що повідомили. Напишіть, будь ласка, номер деталі з інструкції й надішліть фото комплекту. Відсутню деталь надішлемо безкоштовно; якщо меблі збирав наш майстер, він приїде й завершить складання.

**Повернення товару належної якості:**
> Ви можете відмовитися від покупки протягом 14 днів з дня отримання, якщо товар не був у використанні та збережено його вигляд і комплектність. Витрати на повернення ми беремо на себе. Виняток — меблі, виготовлені за вашим індивідуальним замовленням. Станом на [дата], детальніше — у політиці повернення: [посилання].

**Гарантія (просів диван, скрипить):**
> Перепрошуємо за незручності. Надішліть, будь ласка, фото або відео, дату доставки та номер замовлення. Гарантія діє … міс. від дня доставки (або складання нашим майстром). Ми узгодимо з виробником огляд або виїзд майстра й повідомимо строк.

**Скільки коштує доставка:**
> Доставка по Києву безкоштовна для замовлень від 19 000 грн за товари. Підйом на поверх і складання оплачуються окремо: [тарифи]. Для замовлень на меншу суму та за межі Києва вартість доставки ми повідомимо до оформлення замовлення.

**«Це масив?»:**
> Каркас і ніжки — масив бука, корпус — ЛДСП 16 мм, фасади — МДФ у шпоні дуба. Тож це поєднання масиву, плити та натурального шпону; так меблі легші й стабільніші за розмірами.

## 6. Чек перед публикацией

1. Габариты Ш×Г×В в см; спальное место и упаковка указаны.
2. Материалы по элементам; нет «натуральне дерево» для плиты и «натуральна шкіра» для экокожи.
3. Нет недоказанных заявлений и классов эмиссии без документа.
4. Страна производства — по документам; бренд ≠ производство.
5. Условия доставки и возврата — с датой редакции.
6. Нет закупочных данных и ссылок на поставщиков.
7. Текст на украинском; `lint_content` без ERROR.
